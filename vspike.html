А. Shift-reload (контроллер null). Нажмите Shift+Reload (macOS: ⌘⇧R). Страница должна показать жёлтый баннер, проверки виртуальных URL — упасть (это штатный сценарий blob-fallback). Обычная перезагрузка возвращает контроллер.

Б. Убийство SW во время воспроизведения. Запустите видео, затем остановите воркер: Chrome — chrome://serviceworker-internals → Stop (или DevTools → Application → Service workers → stopworker); Firefox — about:debugging#/runtime/this-firefox; Safari — Разработка → Service Workers (или просто подождите ~30 с простоя SW). Продолжите просмотр и перемотку: воспроизведение должно продолжиться (SW рестартует stateless, в журнале появятся новые Range-запросы).

В. Имитация холодного старта. Кнопка «Сброс memo SW» очищает мемоизацию в воркере — следующий Range-запрос обязан заново прочитать Blob из IndexedDB (перемотка продолжает работать).
