А. Shift-reload (контроллер null). Нажмите Shift+Reload (macOS: ⌘⇧R). Страница покажет жёлтый баннер; кнопка «2» создаст оболочку в blob-режиме — это штатный сценарий fallback (§5.0: та же оболочка, меняются только URL). Обычная перезагрузка возвращает контроллер и SW-режим.

Б. Убийство SW во время воспроизведения. Запустите видео (в SW-режиме), затем остановите воркер: Chrome — chrome://serviceworker-internals → Stop (или DevTools → Application → Service workers → stopworker); Firefox — about:debugging#/runtime/this-firefox; Safari — Разработка → Service Workers (или просто подождите ~30 с простоя SW). Продолжите просмотр и перемотку: воспроизведение должно продолжиться (SW рестартует stateless, в журнале появятся новые Range-запросы).

В. Имитация холодного старта. Кнопка «Сброс memo SW» очищает мемоизацию в воркере — следующий Range-запрос обязан заново прочитать Blob из IndexedDB (перемотка продолжает работать).

Г. Кнопка «Назад» после оболочки. Строки «вставка iframe без записей истории» и «hash-навигация» замеряют совместную историю автоматически; после их зелёного состояния кнопка «Назад» браузера должна уводить со стенда, а не листать внутренние состояния iframe.
